## Task Contract

### Fresh candidate and Linux branch

The shared candidate is frozen only after Tasks 19 and 23's final clean committed
source exists. It contains no platform package/runtime/direct-engine/toolchain,
profile, result, evidence-index, platform-graph, or aggregate digest. The Linux
platform input then binds exact Linux application packages, qualification
catalog/keyring/origin, CPU/CUDA runtime archives, toolchains, direct engines,
qualification server, notices/SBOM/provenance, and the predecessor selected at
the shared cutoff. It contains no profile or evidence digest.

Profiles bind only the shared and Linux input digests plus frozen methods,
hardware class, tools, algorithms, repetitions, units, tolerances, and bounds.
The Linux graph binds the complete sorted profile set. Measurement series,
result, and index bind only already-frozen earlier layers. Reject legacy
cycles, placeholders, fixed points, backward/missing edges, mixed candidates,
duplicates, private fields, and noncanonical bytes.

The interrupted pre-revision-17 run is diagnostic history only. Cached model,
corpus, source, or runtime bytes may be reused only after full exact identity
verification; its candidate timestamp, package identities, partial rows, raw
samples, and evidence documents must not be adopted.

### Qualification trust and transports

Use an isolated temporary qualification key and exact loopback HTTPS runtime
origin. The server binds only `127.0.0.1`, serves only frozen runtime objects,
pins certificate/origin/range/ETag/archive identity, and terminates with the
run. The private key stays outside repository/evidence and is destroyed or
revoked after sanitized evidence freezes.

Exercise one exact public Hugging Face model transfer through the approved
anonymous redirect policy, including fresh expiring CDN URL, resume,
cancellation, range/validator behavior, privacy, and whole-object verification.
No token, cookie, private header, moving branch, mirror, or fallback is allowed.

### CPU/CUDA and model matrix

Every canonical model must pass load, bounded warm-up, pinned FLEURS/direct-
engine parity within 1.00 absolute WER percentage point, owned-resource
measurement, unload, and recovery on Linux CPU and available NVIDIA CUDA.
`base/full` additionally passes median RTF `<= 1.0` over the five exact
60-second fixtures.

CPU proves no GPU initialization. CUDA proves the exact selected device and
owned VRAM without exposing native identity. Sampling uses the frozen 100-ms
PSS/NVML method; missing permissions, ownership ambiguity, gaps over 500 ms,
or sampler failure invalidates rather than estimates. Apply upward 64-MiB
rounding, frozen tolerances, repetitions, leak trend, and ten-second/ten-zero-
sample settlement exactly.

Run cancellation, crash/reload, 10 load/unload cycles, 20 sequential
transcriptions, provider switch, suspend/resume, app exit, offline restart,
and exact process/allocation cleanup. No failed row is omitted or converted to
Pass.

### Packages, privacy, and predecessor

Validate AppImage, DEB, and RPM package identities, ASAR/resource boundaries,
exact native helpers, runtime dependency closure, qualification marking, and
release-collection rejection. No generated package/build/private evidence is
committed.

Select the highest stable release published before the shared cutoff. If no
later stable exists, execute `GPT-Voice-2.3.0.AppImage` with SHA-256
`80674b3a90222b51981fb43b5b757b7af9d3e38a5ff4ca41554ab965ae29f111`.
It must remain Not ready, preserve new namespaces, execute/delete no Local
Whisper data, and recover to a provider it knows.

Raw paths, host/device identities, environment data, audio, transcripts,
private keys, and raw measurements remain private. Checked-in evidence contains
only bounded sanitized identities, verdicts, and SHA-256 links.
